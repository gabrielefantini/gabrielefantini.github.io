**1.**

```python
celsius = float(input("Temperature in °C: "))
fahrenheit = celsius * 9 / 5 + 32
print(f"{celsius} °C = {fahrenheit:.1f} °F")
```

Input `21.5` prints `21.5 °C = 70.7 °F`. We use `float`, not `int`, because temperatures can have decimals. The conversion happens once, at the boundary, right where the text comes in.

**2.** (a) `123`: an empty separator. (b) `2.333`: three decimals. (c) `00042`: padded with zeros to width 5. (d) `****hi****`: centred (`^`) in width 10, filled with `*`. (e) `x * 2 = 10`: the `=` spec prints the expression's text, then its value (spaces around `=` are kept).

**3.**

```python
while True:
    line = input(">>> ")
    if line == "quit":
        break
    try:
        print(eval(line))
    except Exception as err:
        print("error:", err)
```

`1/0` now prints `error: division by zero`, and `hello` prints `error: name 'hello' is not defined`. The loop keeps going. The structure "try the risky step, catch the failure, report it and carry on" is how every server and interactive tool survives bad input.

**4.**

```python
import sys

total = 0.0
for line in sys.stdin:
    line = line.strip()
    if line:                 # skip blank lines
        total += float(line)
print(total)
```

`printf "1\n2\n3\n" | python3 sum_lines.py` prints `6.0`. The program never knows whether its input came from the keyboard, a file or another program. `for line in sys.stdin` reads until **end of input**: Ctrl-D in a terminal, the end of the file, or the other program finishing. `strip()` removes the trailing newline, and skipping empty lines avoids `float("")` errors.

**5.** So that progress messages **don't get mixed into the data**. Suppose `convert.py` writes converted records to stdout, and another program consumes them:

```bash
python3 convert.py < input.csv | python3 load_into_db.py
```

If "processing file 3 of 10…" went to stdout, `load_into_db.py` would try to load it as a record and fail, or worse, store garbage. On stderr, the message goes straight to your terminal while the clean data flows through the pipe. **Rule of thumb: stdout is for the program's output, the thing you'd want to save or pipe. Everything addressed to a human goes to stderr.**

**6. ★**

```python
import sys


def rpn(expression, memory):
    """Tuesday's RPN interpreter, extended with variables."""
    stack = []
    for token in expression.split():
        if token in ("+", "-", "*", "/"):
            if len(stack) < 2:
                raise ValueError(f"'{token}' needs two operands")
            b = stack.pop()
            a = stack.pop()
            if token == "+":
                stack.append(a + b)
            elif token == "-":
                stack.append(a - b)
            elif token == "*":
                stack.append(a * b)
            else:
                stack.append(a / b)
        elif token in memory:            # a variable: push its value
            stack.append(memory[token])
        else:
            try:
                stack.append(float(token))
            except ValueError:
                raise ValueError(f"unknown name {token!r}") from None
    if len(stack) != 1:
        raise ValueError(f"expected one result, found {len(stack)} values")
    return stack[0]


memory = {}
while True:
    try:
        line = input("rpn> ").strip()
    except EOFError:                     # Ctrl-D, or the end of piped input
        break
    if line in ("", "quit"):
        if line == "quit":
            break
        continue
    try:
        if "=" in line:                  # assignment: name = expression
            name, expr = line.split("=", 1)
            name = name.strip()
            if not name.isidentifier():
                raise ValueError(f"invalid variable name {name!r}")
            memory[name] = rpn(expr, memory)
            print(f"{name} = {memory[name]}")
        else:
            print(rpn(line, memory))
    except (ValueError, ZeroDivisionError) as err:
        print("error:", err, file=sys.stderr)
```

A session:

```text
rpn> x = 3 4 +
x = 7.0
rpn> x 2 *
14.0
rpn> y 1 +
error: unknown name 'y'
rpn> 1 0 /
error: float division by zero
```

The key change from Tuesday is one new branch: **a token that's a known name pushes its stored value**. The dictionary `memory` is the interpreter's *environment*, the mapping from names to values. That's exactly Wednesday's "labels tied to values", now implemented by you. Errors go to stderr, so `python3 calc.py < program.txt > results.txt` keeps the results file clean. Handling `EOFError` makes the REPL end gracefully when its input runs out, so it works with pipes too.
