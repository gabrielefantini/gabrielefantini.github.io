**5. ★** The new branch changes `pc` instead of moving on:

```python
    elif op == "JNZ":
        if acc != 0:
            pc = arg
```

The program, with instruction numbers:

```python
countdown = [
    ("LOAD", 3),     # 0
    ("PRINT", None), # 1  <- loop starts here
    ("SUB", 1),      # 2
    ("JNZ", 1),      # 3  back to 1 while acc != 0
    ("HALT", None),  # 4
]
```

It prints `3`, `2`, `1`. After printing 1 and subtracting, `acc` is 0, so `JNZ` doesn't jump and execution falls through to `HALT`. In total the machine executes 11 instructions, from a program of only 5.

That's the point. **Without jumps, `pc` only ever increases, so a program of 5 instructions runs at most 5 steps.** The amount of work is limited by the length of the program. With a conditional jump, a short program can run for as long as it needs, and it can *decide* what to do based on data. Loops and `if` statements in every language compile down to conditional jumps. Add enough memory, and this tiny machine can compute anything any computer can (it's *Turing complete*, week 53).
