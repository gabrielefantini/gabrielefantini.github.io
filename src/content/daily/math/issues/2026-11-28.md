## The week in one page

This week wasn't about numbers. It was about the **language** every other week will be written in. Here's how the five days fit together.

**Monday: propositions and connectives.** A proposition is true or false. The connectives $\lnot, \land, \lor, \to, \leftrightarrow$ combine them, and each is just a colouring of the $2 \times 2$ truth grid. There are exactly $2^4 = 16$ ways to colour it. The one to remember: **$P \to Q$ is a promise, broken only when $P$ is true and $Q$ is false**, so $P \to Q \equiv \lnot P \lor Q$.

**Tuesday: quantifiers.** $\forall$ is a giant "and", $\exists$ a giant "or". **Order matters**: "every row has a dot" ($\forall x\,\exists y$) is not "some row is full" ($\exists x\, \forall y$). To negate, push $\lnot$ inward and flip each quantifier it passes. The negation of an implication is $P \land \lnot Q$.

**Wednesday: sets.** Every predicate defines a set, and every set operation is a connective in disguise: $\cup = \lor$, $\cap = \land$, complement $= \lnot$. So every law of logic is a law of sets. A set with $n$ elements has $2^n$ subsets, one per yes/no string.

**Thursday: products and relations.** $A \times B$ is the grid of all ordered pairs. A relation is any set of dots on that grid, and a function is a relation with exactly one dot per column. Reflexive + symmetric + transitive = **equivalence relation**, which is the same thing as sorting a set into boxes.

**Friday: proof.** Direct proof: unpack definitions, compute, repack. Contrapositive: $P \to Q \equiv \lnot Q \to \lnot P$, the same cell of the grid. Contradiction: assume the opposite, reach nonsense. And to kill a "for all", **one counterexample is enough**.

> **The thread running through it all.** Monday's $2\times2$ grid came back every day: as a truth table, as the "who loves whom" picture, as a Venn diagram, as a Cartesian product, and as the reason the contrapositive works. When something feels abstract, ask: *what does the grid look like?*

Next week we use this grammar on its first real subject: **numbers**. We'll look at primes, Euclid's algorithm, and the irrationality of $\sqrt{2}$.

## Mixed problems

**1.** Is $\big(P \to (Q \to R)\big) \leftrightarrow \big((P \land Q) \to R\big)$ a tautology? Answer with a truth table, then explain in words why it makes sense.

**2.** Negate and simplify: "Every student in this class has solved at least one problem that nobody else solved."

**3.** Let $A = \{1, 2, 3, 4\}$. How many subsets of $A$ contain the element 1? How many contain 1 but not 2? Explain using the yes/no picture.

**4.** On $\mathbb{R}$, define $x \sim y$ iff $x - y \in \mathbb{Z}$. Prove it's an equivalence relation. Which class does $3.7$ belong to? Describe the set of classes geometrically (hint: think of wrapping the real line around something).

**5.** Prove: for every integer $n$, $n^2 + n$ is even. Give two proofs: one splitting into cases ($n$ even / $n$ odd), one using a factorisation.

**6.** Prove by contradiction: if $a$ is rational and $b$ is irrational, then $a + b$ is irrational. (You may use that sums and differences of rationals are rational.)

**7. ★** *Synthesis.* For a relation $R$ on a set $A$, write each property as a quantified formula, then negate it: (a) reflexive, (b) symmetric, (c) transitive. Use your negations to give, on $A = \{1, 2, 3\}$, a relation that is symmetric and transitive but **not** reflexive. Then find the flaw in this famous "proof" that symmetric + transitive implies reflexive: *"Take any $a$. Pick $b$ with $a \mathrel R b$. By symmetry $b \mathrel R a$, and by transitivity $a \mathrel R a$."*
