**1.** $A = \{2, 4, 6, 8, 10\}$ and $B = \{3, 6, 9\}$.

- $A \cup B = \{2, 3, 4, 6, 8, 9, 10\}$
- $A \cap B = \{6\}$, the multiples of 6
- $A \setminus B = \{2, 4, 8, 10\}$
- $B \setminus A = \{3, 9\}$
- $(A \cup B)^c = \{1, 5, 7\}$

Check with De Morgan: $A^c = \{1,3,5,7,9\}$ and $B^c = \{1,2,4,5,7,8,10\}$, so $A^c \cap B^c = \{1,5,7\}$. ✓

**2.** (a) **True.** $\{\varnothing\}$ is a set with one element, and that element is $\varnothing$.
(b) **True.** The empty set is a subset of every set.
(c) **False.** The elements of $\{1,2\}$ are the numbers $1$ and $2$. The *set* $\{1\}$ is not one of them.
(d) **True.** Its only element, $1$, is in $\{1, 2\}$.
(e) **True.** $\varnothing$ (a box with nothing in it) and $\{\varnothing\}$ (a box containing an empty box) are different objects, so the set has **2** elements. Keep the "box" picture: $\in$ asks "is this inside the box?", while $\subseteq$ asks "is everything in this box also in that box?"

**3.** For any $x$:

$$
x \in A \setminus B \iff (x \in A \land x \notin B) \iff (x \in A \land x \in B^c) \iff x \in A \cap B^c.
$$

Same elements, so the sets are equal. $\blacksquare$

**4.** We prove both directions.

($\Rightarrow$) Suppose $A \subseteq B$. Always $A \cap B \subseteq A$ (an element of both is in particular in $A$). Conversely, if $x \in A$ then $x \in B$ by hypothesis, so $x \in A \cap B$. Hence $A \subseteq A \cap B$, and the two inclusions give $A \cap B = A$.

($\Leftarrow$) Suppose $A \cap B = A$. If $x \in A$, then $x \in A \cap B$, so in particular $x \in B$. Hence $A \subseteq B$. $\blacksquare$

The structure "prove $\subseteq$ both ways" is the standard way to prove two sets are equal.

**5.** Fill the Venn diagram from the inside out. Both: $7$. Only French: $18 - 7 = 11$. Only German: $15 - 7 = 8$. Studying at least one: $11 + 7 + 8 = 26$, which is also $18 + 15 - 7$. We subtract 7 because the "both" students were counted twice: once with French, once with German. Neither: $30 - 26 = $ **4 students**.

This is the simplest case of *inclusion–exclusion*: $|A \cup B| = |A| + |B| - |A \cap B|$ (week 61).

**6. ★** (a) $x \in A \mathbin\triangle B$ means "$x$ is in exactly one of the two sets": $(x\in A \land x \notin B) \lor (x \in B \land x \notin A)$. That's **exclusive or**, XOR. Its Venn diagram is the two "only" regions, without the overlap.

(b) $A \mathbin\triangle B = \varnothing$ iff both $A \setminus B$ and $B \setminus A$ are empty (a union is empty iff both pieces are). $A \setminus B = \varnothing$ means no element of $A$ is outside $B$, i.e. $A \subseteq B$. Likewise $B \subseteq A$. Together, $A = B$. $\blacksquare$

(c) **Yes, it's associative**, because XOR is. Think of XOR as "add the truth values mod 2" (T = 1, F = 0): $1 \oplus 1 = 0$, $1 \oplus 0 = 1$, and addition mod 2 is associative. So $x \in A \mathbin\triangle B \mathbin\triangle C$ iff $[x\in A] + [x \in B] + [x \in C]$ is odd: **$x$ is in an odd number of the three sets** (exactly one, or all three). In a three-circle Venn diagram that's the three "only" regions plus the centre.

This is exactly how parity bits work in error detection (week 66), and how the XOR swap trick works in programming.
