## A bag with no order and no repeats

A **set** is a collection of objects, called its **elements**. That's it. Two rules make sets different from lists:

- **Order doesn't matter:** $\{1, 2, 3\} = \{3, 1, 2\}$.
- **Repeats don't count:** $\{1, 1, 2\} = \{1, 2\}$.

We write $x \in A$ for "$x$ is an element of $A$" and $x \notin A$ for its negation. Two sets are equal when they have exactly the same elements:

$$
A = B \iff \forall x\; (x \in A \leftrightarrow x \in B).
$$

There are two ways to describe a set:

- **By listing**: $A = \{2, 3, 5, 7\}$.
- **By a property** (set-builder notation): $A = \{\, n \in \mathbb{N} : n \text{ is prime and } n < 10 \,\}$. Read the colon as "such that".

The second way is where yesterday's predicates come back: **every predicate defines a set**, the set of things that make it true. $\{x \in \mathbb{R} : x^2 > x\}$ is the set where yesterday's $P(x)$ holds. It's $(-\infty, 0) \cup (1, +\infty)$.

A few sets are so common they get special letters: $\mathbb{N}$ (natural numbers $0, 1, 2, \dots$), $\mathbb{Z}$ (integers), $\mathbb{Q}$ (rationals), $\mathbb{R}$ (reals). And there's the **empty set** $\varnothing = \{\}$, which has no elements at all.

**Subsets.** $A \subseteq B$ means every element of $A$ is also in $B$: $\forall x\,(x \in A \to x \in B)$. Notice the implication. Because an implication with a false hypothesis is true, **the empty set is a subset of every set**: "every element of $\varnothing$ is in $B$" can never be broken, since there's no element to break it.

## Operations: logic in disguise

Fix a "universe" $U$ that contains everything we're talking about. Then:

| Set operation | Definition | Logic |
| --- | --- | --- |
| Union $A \cup B$ | $\{x : x \in A \lor x \in B\}$ | or |
| Intersection $A \cap B$ | $\{x : x \in A \land x \in B\}$ | and |
| Complement $A^c$ | $\{x \in U : x \notin A\}$ | not |
| Difference $A \setminus B$ | $\{x : x \in A \land x \notin B\}$ | and not |

Look at the right-hand column. Each set operation is *defined by* a logical connective. So **every law of logic is automatically a law of sets.** Monday's truth tables now become pictures of regions, called **Venn diagrams**:

Count the regions in a two-circle Venn diagram: inside both, only $A$, only $B$, outside both. **Four regions — the four rows of a truth table.** It's the same picture as Monday's $2\times2$ grid, just drawn with circles. With three sets you get $2^3 = 8$ regions, one per row of a three-variable truth table.

### De Morgan's laws for sets

Since $\lnot(P \land Q) \equiv \lnot P \lor \lnot Q$, we get for free:

$$
(A \cap B)^c = A^c \cup B^c, \qquad (A \cup B)^c = A^c \cap B^c.
$$

"Not in both" means "missing from at least one". A proof of the first, in one line, by translating to logic:

$$
x \in (A\cap B)^c \iff \lnot(x\in A \land x \in B) \iff x \notin A \lor x \notin B \iff x \in A^c \cup B^c.
$$

> **The big picture.** You never need to memorise set identities. Translate each set into the predicate "$x \in \ldots$", use logic, and translate back. Sets are logic you can draw.

## How many subsets?

The **power set** $\mathcal{P}(A)$ is the set of all subsets of $A$. For $A = \{a, b, c\}$:

$$
\mathcal{P}(A) = \big\{ \varnothing, \{a\}, \{b\}, \{c\}, \{a,b\}, \{a,c\}, \{b,c\}, \{a,b,c\} \big\}.
$$

Eight subsets. Here's why it's always a power of two. To build a subset, walk through the elements one by one and make a yes/no decision for each: is $a$ in? is $b$ in? is $c$ in? Three independent binary choices give $2 \times 2 \times 2 = 8$ subsets. For a set with $n$ elements:

$$
|\mathcal{P}(A)| = 2^n.
$$

If you write "yes" as 1 and "no" as 0, every subset of $\{a, b, c\}$ becomes a 3-bit string: $\{a, c\} \mapsto 101$. Subsets of an $n$-element set are exactly the $n$-bit binary numbers. Programmers use this all the time: an integer used as a **bitmask** *is* a subset, and `|`, `&`, `~` on bits are union, intersection and complement.

> **Why it matters.** The same yes/no counting will return in week 24 (combinatorics), and Cantor will use power sets in week 59 to show that some infinities are bigger than others.

## Exercises

**1.** Let $U = \{1, 2, \dots, 10\}$, $A = \{x : x \text{ is even}\}$, $B = \{x : x \text{ is a multiple of } 3\}$. List $A \cup B$, $A \cap B$, $A \setminus B$, $B \setminus A$ and $(A \cup B)^c$.

**2.** True or false? Explain. (a) $\varnothing \in \{\varnothing\}$; (b) $\varnothing \subseteq \{\varnothing\}$; (c) $\{1\} \in \{1, 2\}$; (d) $\{1\} \subseteq \{1, 2\}$; (e) $|\{\varnothing, \{\varnothing\}\}| = 2$.

**3.** Using the translation into logic, prove that $A \setminus B = A \cap B^c$.

**4.** Prove that $A \subseteq B$ if and only if $A \cap B = A$.

**5.** A class has 30 students. 18 study French, 15 study German, and 7 study both. How many study neither? Draw the Venn diagram.

**6. ★** The *symmetric difference* is $A \mathbin{\triangle} B = (A \setminus B) \cup (B \setminus A)$. (a) Which logical connective does it correspond to? (b) Show that $A \mathbin{\triangle} B = \varnothing$ if and only if $A = B$. (c) Is $\triangle$ associative, i.e. is $(A \mathbin\triangle B) \mathbin\triangle C = A \mathbin\triangle (B \mathbin\triangle C)$? Describe in words which elements are in $A \mathbin\triangle B \mathbin\triangle C$.
