**1.** $A \times B = \{(0,a), (0,b), (0,c), (1,a), (1,b), (1,c)\}$, 6 elements. $A \times A = \{(0,0), (0,1), (1,0), (1,1)\}$, 4 elements.

A relation from $A$ to $B$ is any subset of $A \times B$. A set with 6 elements has $2^6$ subsets (Wednesday: one yes/no choice per dot), so there are **64 relations**.

**2.**

| | Reflexive | Symmetric | Transitive |
| --- | --- | --- | --- |
| $R_1$ | yes | yes | yes |
| $R_2$ | no | no | no |
| $R_3 = \varnothing$ | no | yes | yes |
| $R_4$ (everything) | yes | yes | yes |

(a) $R_1$ contains the diagonal and is mirror-symmetric. Every chain closes: $1 \to 2 \to 1$ needs $(1,1)$ ✓, and $2 \to 1 \to 2$ needs $(2,2)$ ✓. So it's an equivalence relation, with classes $\{1, 2\}$ and $\{3\}$.

(b) $(1,1) \notin R_2$, so it's not reflexive. $(1,2) \in R_2$ but $(2,1) \notin R_2$, so it's not symmetric. The chain $1 \to 2 \to 3$ would need $(1,3)$, which is missing, so it's not transitive.

(c) The empty relation is not reflexive, because $(1,1)$ is missing. But symmetry and transitivity are implications ("*if* $a \mathrel R b$, then…"), and with no pairs the hypothesis is never true. So both hold **vacuously**, just like $\varnothing \subseteq B$ on Wednesday.

(d) Everything is related to everything: one single class.

**3.** (a) **Yes.** "Same birth year" means "same value of the function *year*". Any relation of the form "$f(a) = f(b)$" is an equivalence relation, because $=$ is. The classes are the birth years.
(b) **No.** It isn't reflexive: you're not your own sibling. It also isn't transitive: if Anna is Bea's sibling, then Bea is Anna's sibling, but Anna isn't Anna's sibling. Half-siblings break transitivity too.
(c) **No.** It's reflexive and transitive but not symmetric. Such a relation is called a *preorder* (week 59).

**4.** *Reflexive:* $a - a = 0 = 2 \cdot 0$ is even. *Symmetric:* if $a - b = 2k$, then $b - a = 2(-k)$. *Transitive:* if $a - b = 2k$ and $b - c = 2h$, then $a - c = 2(k + h)$. There are **two classes**: the even integers and the odd integers. This is the same argument as in the issue with 3 replaced by 2, and it works for any modulus $n$, giving $n$ classes (week 60).

**5.** $x^2 + y^2 \le 4$ is the closed disc of radius 2 centred at the origin. $y \ge x$ is the half-plane on or above the diagonal $y = x$. Together they form the **closed half-disc above the diagonal**: a semicircle cut along the line $y = x$.

It is **not a function** from $\mathbb{R}$ to $\mathbb{R}$, for two separate reasons. First, at $x = 0$ every $y \in [0, 2]$ is related to $0$, so that column has infinitely many dots. Second, at $x = 3$ no $y$ is related to it at all (the disc ends at $x = 2$), so that column is empty. A function needs **exactly one** dot in every column.

**6. ★** *Reflexive:* $(a,b) \sim (a,b)$ because $ab = ba$. *Symmetric:* if $ad = bc$, then $cb = da$, which is exactly $(c,d) \sim (a,b)$.

*Transitive:* suppose $(a,b) \sim (c,d)$ and $(c,d) \sim (e,f)$, so $ad = bc$ and $cf = de$. We want $af = be$. Multiply the first equation by $f$:

$$
adf = bcf = b(cf) = b(de) = bde.
$$

So $d \cdot (af) = d \cdot (be)$. Since $d \neq 0$ we can cancel it: $af = be$. $\blacksquare$

We needed exactly **$d \neq 0$**, the second component of the *middle* pair. If $(0, 0)$ were allowed, then $(1,2) \sim (0,0)$ and $(0,0) \sim (5,7)$ would both hold (both sides are 0), but $(1,2) \not\sim (5,7)$. Transitivity would fail. That's the real reason you can't divide by zero.

The classes are **the rational numbers**. The class of $(1,2)$ is $\{(1,2), (2,4), (-3,-6), \dots\}$, and that class *is* the fraction $\tfrac12$. "$\tfrac{1}{2} = \tfrac{2}{4}$" is the statement that two pairs lie in the same box. This is how $\mathbb{Q}$ is actually constructed from $\mathbb{Z}$, and you'll meet the idea again in week 2.
