**1.** Let $a = 2k + 1$ and $b = 2h + 1$ with $k, h \in \mathbb{Z}$. Then

$$
ab = 4kh + 2k + 2h + 1 = 2(2kh + k + h) + 1,
$$

which has the form $2m + 1$ with $m = 2kh + k + h \in \mathbb{Z}$. So **$ab$ is odd**. $\blacksquare$

**2.** Suppose $a \mid b$ and $b \mid c$: $b = ak$ and $c = bh$ for some integers $k, h$. Substitute the first into the second: $c = (ak)h = a(kh)$. Since $kh$ is an integer, $a \mid c$. $\blacksquare$ (So divisibility is a *transitive relation*, in the language of Thursday.)

**3.** Let $P$ = "it's a square" and $Q$ = "its diagonals are equal". The original $P \to Q$ is **true**.

- **Contrapositive** ($\lnot Q \to \lnot P$): "If a quadrilateral's diagonals are not equal, then it's not a square." **True**, since it's equivalent to the original.
- **Converse** ($Q \to P$): "If a quadrilateral's diagonals are equal, then it's a square." **False.** A $1 \times 2$ rectangle has equal diagonals and isn't a square. So does an isosceles trapezoid.

**4.** *First claim.* Contrapositive: "if $n$ is even, then $n^2$ is even". If $n = 2k$ then $n^2 = 4k^2 = 2(2k^2)$, which is even. $\blacksquare$

*Second claim.* This one is already in a convenient form, so we prove it directly. If $3 \nmid n$, the remainder of $n$ when divided by 3 is 1 or 2:

- $n = 3k + 1$: $n^2 = 9k^2 + 6k + 1 = 3(3k^2 + 2k) + 1$, remainder 1.
- $n = 3k + 2$: $n^2 = 9k^2 + 12k + 4 = 3(3k^2 + 4k + 1) + 1$, remainder 1.

Either way **$n^2$ leaves remainder 1**, so $3 \nmid n^2$. $\blacksquare$ (Its contrapositive, "if $3 \mid n^2$ then $3 \mid n$", is what you'd use to prove $\sqrt3$ is irrational.)

**5.** (a) $a = 1$, $b = -1$: $a^2 = b^2 = 1$ but $a \ne b$. (b) $2$ is prime and even. (c) $n = 2$: $2^2 = 4$ and $2^2 = 4$, so $4 > 4$ is false. ($n = 3$ and $n = 4$ also fail. The inequality does hold for $n = 1$ and every $n \ge 5$, which you can prove by induction in week 23.)

**6. ★** Suppose, for contradiction, that integers $a, b$ satisfy $4a + 6b = 1$. The left side is $2(2a + 3b)$, which is even. The right side, 1, is odd. An integer can't be both even and odd, so this is a contradiction, and **no such integers exist**. $\blacksquare$

*Generalisation.* The same argument shows $4a + 6b$ is always even, so $c$ must be **even**. Conversely, every even $c$ works. $a = -1$, $b = 1$ gives $-4 + 6 = 2$. So for $c = 2m$, take $a = -m$, $b = m$: $4(-m) + 6m = 2m$. ✓

So $4a + 6b = c$ is solvable **exactly when $c$ is a multiple of 2**, and $2 = \gcd(4, 6)$. That's no coincidence. **Bézout's identity** (week 60) says that $xa + yb = c$ has integer solutions exactly when $\gcd(x, y)$ divides $c$.
