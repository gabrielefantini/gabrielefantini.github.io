# gabrielefantini.github.io

Personal website of **Gabriele Fantini** — software engineer working on data governance, data products and data mesh at [Blindata](https://blindata.io) and in the [Open Data Mesh Initiative](https://github.com/opendatamesh-initiative).

Built with **React + TypeScript + Vite**, deployed to **GitHub Pages** by GitHub Actions.

## Develop

```bash
npm install
npm run dev        # http://localhost:5173 (drafts are visible here)
npm run build      # type-check + production build into dist/
npm run preview    # serve the production build
```

### Writing a post

Create `src/content/blog/my-post.md` (the file name is the URL slug):

```markdown
---
title: My post
date: 2026-11-07
summary: One sentence shown on the cards.
art: mesh-dark
tags: [data mesh, dpds]
draft: false
---

Markdown body, with GitHub-flavoured tables, code blocks, etc.
```

`draft: true` posts only show up in `npm run dev`.

### Illustrations

All images are SVG neon line art generated by `npm run art`. Available names (each with `-dark` and `-light`):
`flow`, `mesh`, `orbits`, `spiro`, `lattice`, `contours`, `rays`, `ribbon`, `banner`.

## Daily newspapers

`/daily/` hosts two daily papers, **The Daily Theorem** (mathematics) and **The Daily Commit**
(software engineering), following 104-week programmes in `src/content/daily/<paper>/syllabus.md`.
A scheduled Claude task writes each week's issues every Monday morning and pushes them to `main`.
Everything about the format is in [`src/content/daily/README.md`](src/content/daily/README.md).

- Issues are Markdown with KaTeX math and inline SVG figures, rendered to HTML at build time
  (`scripts/daily-render.mjs`, `scripts/daily-content.mjs`, the `virtual:daily` plugin in `vite.config.ts`).
- A production build only includes issues dated **today or earlier in Europe/Rome**; the deploy
  workflow also runs daily at 23:30 UTC so each issue goes live on its date. `npm run dev` shows
  future issues too, marked "Scheduled". Preview a given day with `DAILY_DATE=2026-11-25 npm run build`.
- Each issue shows the previous issue's solutions.
- `scripts/daily-pdf.mjs` prints every issue to `dist/daily/<paper>/<date>.pdf` with Playwright
  (cached in `.cache/daily-pdf/`). Locally it needs Chromium: `npx playwright install chromium`.

## Deploy

1. Create a public repo named **`gabrielefantini.github.io`** and push this folder to `main`.
2. In the repo: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. Every push to `main` builds and publishes to <https://gabrielefantini.github.io>.

## SEO

`npm run build` pre-renders every page to static HTML (`scripts/prerender.mjs`, using `src/entry-server.tsx`), so each URL is served with HTTP 200, full content, its own `<title>`/description/canonical, Open Graph tags and schema.org JSON-LD (`Person`, `WebSite`, `ProfilePage`, `BlogPosting`). It also writes `sitemap.xml`, `robots.txt` and a `noindex` `404.html`. New posts are picked up automatically.

The social preview image `public/og.png` is a PNG export of `scripts/og-card.svg` (generated by `npm run art`); re-export it if you change the card.

After deploying, add the site to [Google Search Console](https://search.google.com/search-console) and submit `https://gabrielefantini.github.io/sitemap.xml`.
