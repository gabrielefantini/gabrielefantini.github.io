# gabrielefantini.github.io

Personal website of **Gabriele Fantini** — software engineer working on data governance, data products and data mesh at [Blindata](https://blindata.io) and in the [Open Data Mesh Initiative](https://github.com/opendatamesh-initiative).

Built with **React + TypeScript + Vite**, deployed to **GitHub Pages** by GitHub Actions.

## Develop

```bash
npm install
npm run dev        # http://localhost:5173 (drafts are visible here)
npm run build      # type-check + production build into dist/
npm run preview    # serve the production build
```

## Where things live

| What | Where |
| --- | --- |
| Bio, links, organisations, focus areas, experience | `src/data/site.ts` |
| Projects to sponsor (empty → page shows an empty state) | `sponsored` in `src/data/site.ts` |
| Blog posts | `src/content/blog/*.md` |
| Personal "Life" posts | `src/content/life/*.md` |
| Pages | `src/pages/` |
| Styles / design tokens (light & dark) | `src/styles.css` |
| Neon line-art generator | `scripts/generate-art.mjs` → `public/art/` |
| New GitHub profile README | `profile-readme/` |

### Writing a post

Create `src/content/blog/my-post.md` (the file name is the URL slug):

```markdown
---
title: My post
date: 2026-11-07
summary: One sentence shown on the cards.
art: mesh-dark
tags: [data mesh, dpds]
draft: false
---

Markdown body, with GitHub-flavoured tables, code blocks, etc.
```

`draft: true` posts only show up in `npm run dev`.

### Illustrations

All images are SVG neon line art generated by `npm run art`. Available names (each with `-dark` and `-light`):
`flow`, `mesh`, `orbits`, `spiro`, `lattice`, `contours`, `rays`, `ribbon`, `banner`.

## Deploy

1. Create a public repo named **`gabrielefantini.github.io`** and push this folder to `main`.
2. In the repo: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. Every push to `main` builds and publishes to <https://gabrielefantini.github.io>.

Client-side routes work on refresh thanks to `dist/404.html` (a copy of `index.html` written by `scripts/spa-fallback.mjs`).
